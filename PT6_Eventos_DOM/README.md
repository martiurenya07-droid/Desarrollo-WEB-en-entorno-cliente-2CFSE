# PT6 - Eventos y DOM

He separado cada ejercicio y práctica en su carpeta, con el HTML y el JavaScript en archivos distintos.

## Cómo abrirlo

Abre el `index.html` principal con Live Server en VS Code o directamente desde el navegador. Desde ahí puedes entrar a cada ejercicio.

## Carpetas

- `ejercicio1`: añade números aleatorios a una lista.
- `ejercicio2`: muestra la posición del ratón.
- `ejercicio3`: oculta, elimina y recupera párrafos.
- `practica1`: cambia el fondo con Alt+F12 o Ctrl+B. Necesita Internet para cargar la imagen.
- `practica2`: valida el email y la contraseña al perder el foco.
- `practica3`: arrastra el cuadro amarillo hasta el destino.

Dentro de cada carpeta están `index.html` y `script.js`. El CSS se mantiene dentro del HTML.

Para entregar el trabajo, sube toda la carpeta al repositorio de GitHub y entrega su URL.
