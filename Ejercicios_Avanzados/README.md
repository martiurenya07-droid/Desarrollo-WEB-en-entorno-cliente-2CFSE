# Ejercicios avanzados de JavaScript

Trabajo con ejercicios de cookies, errores, promesas y módulos.

## Cómo abrirlo

1. Abrir esta carpeta en Visual Studio Code.
2. Iniciar **Live Server** desde el `index.html` principal.
3. Entrar a cada ejercicio desde los enlaces.
4. Para ver los `console.log`, abrir la consola del navegador (F12).

Los ejercicios de cookies y los módulos se deben probar con Live Server (no abrir los archivos con `file://`).

## Carpetas

- `ejercicio1`: guarda el nombre en una cookie durante 7 días.
- `ejercicio2`: prueba de división con `try/catch`.
- `ejercicio3`: promesas con `then/catch` y `async/await`.
- `ejercicio4`: calculadora con módulo `calculadora.js`.
- `ejercicio5`: cadena de promesas.
- `practica1`: contador de visitas con cookie de 30 días.
- `practica2`: promesa temporizador de 5 segundos.
- `practica3`: cuenta atrás importada desde `temporizador.js`.

En la práctica 3, el programa principal se encuentra en una etiqueta `<script type="module">` dentro del HTML **porque así lo pide expresamente el enunciado**.
